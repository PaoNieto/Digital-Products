# Digital-Products

Vender archivos y acceso pago a desconocidos por internet, cobrando en dólares con Whop.
Negocio aparte de Vendí.

## Dónde está cada cosa

| Carpeta o archivo | Qué hay adentro |
|---|---|
| **`productos/`** | Un producto por carpeta. Adentro de cada una hay un `LEEME.md` que dice qué abrir |
| `digimones/` | Lo que aprendieron los agentes: videos, fuentes, mercado y precios de otros |
| `CLAUDE.md` | Las reglas del negocio y el estado actual (nicho, precio, ventas, Whop) |
| `CONTEXTO.md` | Por qué se decidió cada cosa |
| `.claude/` | Los manuales de los digimones. No se abre a mano |

## Los productos

| Carpeta | Producto | Estado |
|---|---|---|
| `productos/cintura/` | **Plana todo el día**, reto de 28 días | PDF de 38 páginas listo. Falta la página de venta |
| `productos/fitness-mujeres/` | El ranking de 30 subnichos y la fila de espera | Ranking hecho |

| `productos/eyaculacion-precoz/` | Eyaculación precoz por ansiedad | Solo el brief |

## Qué abrir si solo querés ver el producto

`productos/cintura/producto/plana-todo-el-dia.pdf`

## Una advertencia sobre las rutas

Si una ruta tiene `.claude\worktrees\` en el medio, es una **copia de trabajo** donde un
agente está trabajando sin pisar la carpeta principal. Lo que vale siempre está en la
carpeta de arriba, `C:\Users\Usuario\Digital Products\Digital-Products`, una vez que el
trabajo se pasa con git.
